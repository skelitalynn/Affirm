# 简历最终版

**更新日期**：2026-06-22  
**用途**：提供可直接摘取到正式简历中的项目条目

## 1. 项目名称

Affirm | Telegram 长期陪伴型 AI 显化导师系统

## 2. 项目描述

设计并实现面向长期陪伴场景的 AI 导师系统，围绕跨会话长期记忆、历史事件召回、目标跟进和可治理的工程闭环构建产品与技术方案。

## 3. 精简版项目条目

1. 设计 `messages / profiles / memory_events / knowledge` 分层记忆架构，支持跨会话记忆、历史事件召回和个性化陪伴。
2. 实现 `memory_events` 的写入、hybrid retrieval、rule-based rerank、prompt injection 和后台治理，形成长期记忆第一版效果闭环。
3. 设计回复后异步记忆写回链路，并通过 `sync_jobs`、trace 与多级降级路径提升系统稳定性和可观测性。
4. 建立 `recall / write / injection / utilization / replay / degradation` 多维 Agent eval baseline，覆盖召回、注入、利用和降级行为。
5. 沉淀并接入自定义 `harness-adopter` skill，为已有仓库增量安装 Agent Harness，补充文档路由、任务状态机、验证门控与会话交接工件。

## 1. 项目基本信息

| 项 | 内容 |
|---|---|
| 项目名 | Affirm |
| 产品定位 | Telegram 上的长期陪伴型 AI 显化导师 |
| 核心目标 | 让系统具备跨会话记忆、目标跟进、历史召回和持续陪伴能力 |
| 当前阶段 | `v2-min` 可运行，长期记忆第一版效果闭环已完成 |

| 当前重点 | 不是继续堆功能，而是提炼产品内核并准备更干净的重建 |

## 2. 项目要解决的问题

Affirm 不是普通聊天机器人项目，它想解决的是下面这类问题：

1. 用户希望被持续理解，而不是每次都重新开始
2. 用户的目标、承诺、阻碍和突破，需要被长期跟踪
3. 当用户再次进入类似情境时，系统需要能召回过去相关经历
4. 用户个人历史和外部知识必须分开管理
5. 这套记忆系统不仅要能跑，还要能被观测、治理和验证

## 3. 一句话价值主张

Affirm 提供的不是“回答一次问题”的能力，而是“随着时间积累对用户的理解，并在合适的时候给出更贴身支持”的能力。

## 4. 最值得保留的资产

1. 长期陪伴型辅导定位
2. 用户记忆与外部知识分层的产品边界
3. “稳定画像 + 历史事件召回”的记忆模型
4. 记忆写回链路、命中 trace 和 eval baseline

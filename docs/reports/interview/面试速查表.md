# 面试速查表

**更新日期**：2026-06-22  
**用途**：面试前快速复习，或面试中临时回看

## 1. 项目一句话

Affirm 是一个基于 Telegram 的长期陪伴型 AI 显化导师系统，核心能力是跨会话长期记忆、历史事件召回、目标跟进和可治理的工程闭环。

## 2. 最值得主动强调的 8 个点

1. 这不是单轮聊天机器人，而是长期陪伴型 AI 系统。
2. 我先拆了边界：`messages / profiles / memory_events / knowledge / governance`。
3. 我没有把用户记忆和外部知识混在一起。
4. 我没有把长期记忆更新放进主回复同步链路，而是做了异步写回。
5. `memory_events` 不是只存数据，还接了召回、rerank、prompt 注入和治理。
6. 我考虑了降级：Redis、embedding provider、Knowledge RAG 都不会直接拖垮主链路。
7. 我有一版 `recall / write / injection / utilization / replay / degradation` eval baseline。
8. 我还把 `harness-adopter` skill 接进仓库，补了 Harness 路由、任务状态和验证门控。

## 3. 项目结构速记

1. `messages`：原始日志 + 最近上下文
2. `profiles`：稳定长期记忆
3. `memory_events`：可召回历史事件
4. `Haystack`：外部知识
5. `sync_jobs / trace / admin`：治理和可观测性

## 4. Prompt 顺序速记

`system -> profile memory -> recalled memory events -> recent messages -> knowledge -> user message`

## 5. 主回复链路速记

1. 收消息
2. 保存 user message
3. 读 `profile`
4. 召回 `memory_events`
5. 取最近消息
6. 取知识
7. 组 prompt
8. 生成回复
9. 保存 assistant message
10. 异步更新长期记忆

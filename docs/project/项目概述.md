# 项目概述

**项目名**：Affirm  
**定位**：Telegram 上的 AI 显化导师  
**更新日期**：2026-04-04

## 项目在做什么

Affirm 不是单纯的聊天机器人，而是一个带长期用户数据的对话系统：

- Telegram 接收用户消息
- PostgreSQL 保存消息、用户画像和知识库
- Knowledge RAG 为回复补充外部知识
- Admin 后台负责知识和画像管理
- Notion 用于归档对话

## 当前真实状态

| 能力 | 当前状态 | 说明 |
|------|----------|------|
| Telegram Bot | 可用 | Polling / Webhook 双模式 |
| 多 AI Provider | 可用 | `deepseek` / `claude` / `openai` |
| Knowledge RAG | 可用 | 基于 `LangChain + PGVectorStore` |
| Message 语义记忆 | 停用 | 旧 embedding 链路已下线 |
| Admin 后台 | 可用 | 画像和知识管理 |
| Notion 归档 | 可用 | 通过 `NotionService` |
| BullMQ 队列 | 可用 | Redis 可用时启用，失败时内存降级 |

## 现在不要再误解的点

1. 这个项目当前重点是 `knowledge RAG`，不是 `messages` 语义记忆。
2. `EMBEDDING_API_KEY` 不是必填项。
3. 如果没有可用的远程 embedding key，knowledge RAG 会退回本地 deterministic 向量，系统仍能跑，但检索质量会下降。
4. 旧的“7 天开发计划”和自动日报流程已经删除，不再是开发入口。

## 启动入口

```bash
npm install
npm run db:migrate
npm run verify
npm start
```

后台单独启动：

```bash
npm run admin
```

## 关键环境变量

### 必填

```bash
DB_URL=postgresql://...
TELEGRAM_BOT_TOKEN=...
AI_PROVIDER=deepseek
ADMIN_PASSWORD=...
```

### AI Provider

至少配置一个对应 key：

```bash
DEEPSEEK_API_KEY=...
# 或
CLAUDE_API_KEY=...
# 或
OPENAI_API_KEY=...
```

### Knowledge RAG

优先级从高到低：

1. `EMBEDDING_API_KEY`
2. `OPENAI_API_KEY`
3. 本地 deterministic fallback

相关变量：

```bash
EMBEDDING_API_KEY=
EMBEDDING_BASE_URL=https://api.openai.com/v1
EMBEDDING_MODEL=text-embedding-3-small
EMBEDDING_DIMENSIONS=768
```

### 可选

```bash
REDIS_URL=redis://localhost:6379
WEBHOOK_ENABLED=false
TELEGRAM_WEBHOOK_URL=https://your-domain.com
NOTION_API_KEY=...
NOTION_DATABASE_ID=...
```
